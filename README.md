# Практическая работа №3 «Жёсткие ссылки»

Консольное приложение на C++ рекурсивно обходит указанный каталог, вычисляет
64-битный хэш FNV-1a для каждого обычного файла и заменяет одинаковые файлы
жёсткими ссылками на один оставленный экземпляр.

Решение предназначено для GNU/Linux. Программа не вызывает внешние приложения:
в ней нет `system()`, `popen()`, `fork()` или `exec()`.

## Файлы проекта

- `main.cpp` — исходный код приложения;
- `Makefile` — сборка проекта компилятором `g++`;
- `README.md` — инструкция и соответствие условию.

## Сборка в Linux

```sh
make
```

Эта команда соответствует рассмотренной в презентации схеме сборки через
`g++` и создаёт исполняемый файл `hardlink_dedup`.

## Запуск

```sh
./hardlink_dedup /путь/к/каталогу
```

Пример:

```sh
./hardlink_dedup ./test-data
```

Программа выводит:

1. список найденных обычных файлов;
2. хэш каждого файла;
3. сообщения о заменённых дубликатах;
4. итоговое количество замен.

## Как работает алгоритм

1. `std::filesystem::recursive_directory_iterator` рекурсивно обходит каталог.
2. Символические ссылки, каталоги, устройства и сокеты не обрабатываются.
3. Для каждого обычного файла вычисляется потоковый хэш FNV-1a.
4. Первый файл с найденным хэшем остаётся исходным экземпляром.
5. Для каждого следующего файла с тем же хэшем создаётся временная жёсткая ссылка на
   исходный экземпляр, затем `rename` атомарно ставит её на место дубликата.
6. Если создать ссылку невозможно, исходный файл не удаляется.

После замены имена файлов остаются разными, но они указывают на один inode и
на одни и те же данные в файловой системе.

## Проверка результата в Linux

```sh
ls -li /путь/к/каталогу
```

У файлов-дубликатов должны совпасть номера inode. Число ссылок на inode во
втором столбце должно стать больше единицы.

## Коды завершения

- `0` — обработка успешно завершена;
- `1` — неверное количество аргументов;
- `2` — указанный каталог не существует или недоступен;
- `3` — ошибка обхода, чтения или создания жёсткой ссылки.

## Соответствие условию

| Требование | Реализация |
|---|---|
| Обойти указанный каталог | Рекурсивный обход через стандартную библиотеку C++ |
| Составить список файлов | Список выводится перед обработкой |
| Вычислить хэш каждого файла | 64-битный потоковый FNV-1a |
| Найти одинаковые файлы | Группировка файлов по совпадающему хэшу |
| Оставить один экземпляр | Первый путь в лексикографическом порядке |
| Заменить остальные жёсткими ссылками | `create_hard_link` и атомарный `rename` |
| Не вызывать внешние приложения | Используются только C++ и системные функции текущего процесса |
